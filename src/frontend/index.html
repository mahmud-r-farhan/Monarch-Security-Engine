WordPress & PHP Defense Recommendations

1. Disable XML-RPC

Add to .htaccess or Nginx to prevent multicall brute-force:

<Files xmlrpc.php>
  Require all denied
</Files>

2. Block Author Enumeration

Prevent scanning authors via /?author=N by redirecting in functions.php:

add_action('template_redirect', function() {
  if (is_author()) { wp_redirect(home_url(), 301); exit; }
});

3. Protect /wp-login.php

Place the login page behind HTTP Basic Auth, VPN, or IP allow-listing to neutralize credential stuffing bots.
