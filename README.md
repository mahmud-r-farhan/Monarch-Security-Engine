## Application Overview

The Image Editor is a powerful, web-based tool that allows users to edit and manipulate images directly in their browser. Built with React and Next.js, it offers a range of features from basic editing to advanced image manipulation. The application is designed with a user-friendly interface, making it accessible for both beginners and experienced users.

## Installation

To set up the Image Editor on your local machine, follow these steps:

1. Clone the repository:

```plaintext
git clone https://github.com/mahmud-r-farhan/photo-edit.git
```


2. Navigate to the project directory:

```plaintext
cd Photo-edit
```


3. Install the dependencies:

```plaintext
npm install
```


4. Start the development server:

```plaintext
npm run dev
```


5. Open your browser and visit `http://localhost:3000` to use the application.


## How to Use the Application

1. **Launching the Editor**: Upon opening the application, you'll see a blank canvas with a toolbar on the left, main editing area in the center, and a sidebar on the right.
2. **Importing an Image**:

1. Click the "Import" button in the header.
2. Select an image file from your computer.
3. The image will be loaded onto the canvas.



3. **Using Tools**:

1. Select a tool from the toolbar on the left (e.g., Select, Crop, Move, Text, Draw, Eraser).
2. Each tool has specific functions:

1. Select: Choose objects on the canvas.
2. Crop: Resize the image.
3. Move: Reposition elements.
4. Text: Add text to the image.
5. Draw: Freehand drawing.
6. Eraser: Remove parts of the drawing.






4. **Adjusting Settings**:

1. Use the sidebar on the right to adjust tool-specific settings.
2. For drawing tools, you can change color and brush size.
3. For text, you can modify the content, font size, and color.



5. **Managing Layers**:

1. The sidebar also shows a list of layers.
2. Toggle layer visibility using the checkboxes.



6. **Exporting Your Work**:

1. Once you're satisfied with your edits, click the "Save" button in the header.
2. The edited image will be downloaded to your computer.





## Features

1. **Multi-language Support**:

1. Switch between English, Spanish, Chinese, French, German, and Arabic.
2. Change language in the settings menu.



2. **Dark Mode**:

1. Toggle between light and dark themes for comfortable editing in different lighting conditions.



3. **Responsive Design**:

1. Works on various screen sizes, from desktop to tablet.



4. **Undo/Redo Functionality**:

1. Easily revert or reapply changes.



5. **Layer Management**:

1. Create, reorder, and toggle visibility of layers for complex compositions.



6. **Color Picker**:

1. Choose colors in various formats (RGB, CMYK, HSL).



7. **Text Tool**:

1. Add and edit text with customizable font size and color.



8. **Drawing Tools**:

1. Freehand drawing with adjustable brush sizes and colors.



9. **Image Transformations**:

1. Crop, resize, and move imported images.



10. **File Operations**:

1. Import images from your computer.
2. Export edited images in common formats.



11. **New Canvas Creation**:

1. Start a project from scratch with custom canvas sizes.



12. **Interactive Tour**:

1. A guided tour for new users to learn the interface.



13. **Keyboard Shortcuts**:

1. Efficient editing with keyboard controls for common actions.



14. **Real-time Preview**:

1. See your changes instantly as you edit.



15. **Cross-browser Compatibility**:

1. Works on major modern web browsers.





This Image Editor application provides a comprehensive set of tools for both casual users and professionals to edit and enhance their images directly in the browser. Its intuitive interface, coupled with powerful features, makes it a versatile choice for various image editing needs.
