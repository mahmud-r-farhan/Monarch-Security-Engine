# Automated Web Vulnerability Scanner & Network Analyzer (AI-Powered)

An intelligent, web-based security testing and network monitoring platform designed to inspect target domains, analyze network request lifecycle, perform security scans, and generate actionable remediation reports using AI.

---

## 📌 Project Overview

This project is a web-accessible security auditing suite. Users can input a domain or URL to initiate an automated dynamic audit. The application uses a browser automation engine to crawl the website, monitor all incoming and outgoing network traffic in real-time (similar to Chrome DevTools Network tab), and perform automated security evaluation on configuration, sessions, authentication tokens, and HTTP headers.

Once the scan is completed, an integrated AI engine processes the gathered diagnostic data and provides a structured vulnerability report along with step-by-step defensive remediation guides.

> ⚠️ **Disclaimer**: This tool is strictly intended for **educational purposes, defensive research, and auditing authorized self-hosted applications**. Scanning unauthorized third-party targets is illegal and strictly prohibited.

---

## 🚀 Key Features

* **URL & Domain Crawler**: Automatically explores pages, endpoints, forms, and client-side assets using an automated engine.
* **Built-in Network Inspector (DevTools Style)**: Real-time traffic analyzer capturing HTTP/HTTPS requests, responses, status codes, payload parameters, and response headers.
* **Automated Passive & Active Security Checks**:
  * **Header Configuration**: Checks for missing security headers (`CSP`, `HSTS`, `X-Frame-Options`, `X-Content-Type-Options`).
  * **Cookie & Session Auditing**: Validates `HttpOnly`, `Secure`, and `SameSite` flags on cookies.
  * **JWT Analysis**: Inspects JWT structure, signature algorithm strength, and potential sensitive data exposures.
  * **Basic Vulnerability Heuristics**: Evaluates client-side inputs and parameters for common weakness patterns (XSS, CSRF readiness, insecure storage usage like `localStorage`).
* **AI-Powered Threat Summarizer & Remediation**: Uses LLM APIs to digest network logs and security alerts, providing human-readable risk scores, root-cause analyses, and mitigation code snippets.
* **Exportable Audit Reports**: Generates downloadable PDF/Markdown reports summarizing security posture.

## 📋 Recommended Security Scans & Modules

1. **Session & Token Verification**:
   * Detects sensitive tokens (JWT, Session IDs) stored in unencrypted `localStorage` or `sessionStorage`.
   * Checks if session cookies lack essential protection flags (`HttpOnly`, `Secure`, `SameSite=Strict/Lax`).
2. **Security Headers Verification**:
   * Evaluates missing defense-in-depth headers.
3. **Network Transport Security**:
   * Ensures HTTPS enforcement and flags mixed-content warnings.
4. **AI Risk Assessment**:
   * Categorizes risks into **Critical**, **High**, **Medium**, **Low**, and **Informational**.

## 🛡️ Best Practices & Defensive Guidelines

This project encourages secure development practices. Key recommendations generated by the report often include:

* **HttpOnly Cookies**: Store authentication tokens in `HttpOnly` and `Secure` cookies to prevent token theft via XSS.
* **Content Security Policy (CSP)**: Enforce strict CSP to restrict unauthorized script execution.
* **Input Sanitization**: Always sanitize user inputs on the server side to prevent cross-site scripting (XSS).
* **Strong Token Signing**: Use asymmetric algorithms (such as `RS256`) for signing JWT tokens and enforce expiration (`exp`).
